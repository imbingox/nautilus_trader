# Security policy

Cairn PAPI is an independent, temporary third-party fork. Nautech Systems Pty Ltd does not
provide security support for this fork, and upstream response timelines do not apply here.
No response deadline or long-term maintenance commitment is made.

## Reporting a vulnerability

Do not publish sensitive details in an issue. Use this repository's
[private vulnerability reporting](https://github.com/imbingox/nautilus_trader/security/advisories/new)
if enabled. If unavailable, request a private reporting channel from the fork maintainer through
[this repository](https://github.com/imbingox/nautilus_trader/issues), without including exploit,
credential, account, or other sensitive details.

Include affected versions, reproduction steps, and suggested remediation in the private report.
Do not access unauthorized data or disrupt systems while investigating.

## Upstream security policy

For issues independently confirmed to affect upstream NautilusTrader, consult the
[upstream security policy](https://github.com/nautechsystems/nautilus_trader/blob/develop/SECURITY.md).
This source reference is retained for attribution and upstream reporting; it is not a fork
support channel or a claim that upstream has reviewed this fork.
